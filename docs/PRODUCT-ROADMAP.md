# Block League product roadmap

28 November 2026 · Pilot delivery plan for the [product vision](vision.md#8-progression-sharing-and-repeat-play)

Start with a satisfying repeatable Classic run. Build a reusable puzzle catalogue and reward collection around it. Pilot Daily Puzzles privately, then add opt-in friend streaks and Weekly Board. Prototype CPU Duel alongside the puzzle work because it can reuse the shared rules engine and run offline.

## Pilot rules

**Daily credit.** The pilot uses one midnight UTC boundary for every profile. The app displays the issued deadline in local time and the server pins the assignment and verifies its moves. Device clock and time-zone changes leave the server window intact. Hints count toward participation. A cached puzzle can be finished offline and submitted by the deadline. Late solves remain playable as personal practice. Gather feedback on the cutoff and the 3–5 minute target before considering profile-local windows.

Today’s practice board can also earn a local tile, including for protected profiles. Practice dates and awards stay in personal progress and never count toward friend streaks.

**Friend permissions.** Share the current count and selected awards with mutually accepted friends after consent. Keep best streak, precise activity history and puzzle assignments private by default. Include tests for hiding a result, removing a friend, blocked access, account deletion and protected profile restrictions.

**CPU calibration.** Give each tier a deterministic legal-move policy using the same rules and visible tray. A simple Starter strategy, a Planner that evaluates board space and clears, and an Architect that searches more legal choices within a fixed budget provide a starting test. Compare median score and lockout distributions across common seeds, then observe people playing each tier. Save the bot policy version with the result. Keep live opponent information and future trays outside its decision inputs.

## Implemented pilot scope

- Classic keeps one-tap resume and adds last-run and best-placement review. Journey has six verified solutions and free replays. Daily Puzzle has three difficulties, a paged map, retry and archive practice, and seven-day and thirty-day rewards.
- Friend invitations, streak visibility, equipped verified awards and Weekly Board scores are available to online adult profiles. Sharing starts off and either person can remove the connection. The weekly cutoff is Monday at midnight UTC.
- CPU Duel runs offline and offers three tiers, saved boards, result replays and rematches. Open Table pilots separate untimed chapters and lifetime totals. Monsoon Tile and Kiln & Clay are unlocked through play.
- A larger Journey pack and a shared daily competition remain pilot follow-ups. Review engagement, puzzle completion time and device performance before deciding whether to expand.

[Roadmap pilot QA](ROADMAP-PILOT-QA.md) records browser verification and the remaining release gates.

## Pilot measures and stop decisions

- Compare voluntary Classic replay, daily puzzle completion and return after a missed day against the pilot baseline. Treat a confusing deadline, a lost save or repeated puzzles as reasons to revise the implementation.
- Measure repeat participation by private groups in Weekly Board. Ask friends whether seeing a streak gives them a reason to return and whether they want the visibility controls as designed.
- Check CPU tier choice, completed matches, optional rematches and reported fairness. Recalibrate overlapping tiers before adding more opponents.
- Keep Championship expansion, verified public rankings and commerce behind their separate release decisions. An experiment can be revised or removed after the pilot while earned progress remains available.
